# Police X Heroine Lovepatrina! Love na Rhythm de Taiho Shimasu! English Patch

An unofficial fan-made English translation patch for **Police X Heroine Lovepatrina! Love na Rhythm de Taiho Shimasu!** aka **Police x Heroine Lovepatrina! With the Rhythm of Love We Will Arrest You!** on Nintendo Switch.

This project aims to make the game more accessible to English-speaking players by translating Japanese text, character profiles, dialogue, and other in-game content.

> **Disclaimer:** This is an unofficial fan project. It is not affiliated with, endorsed by, or associated with Nintendo, Columbia, TOMY, OLM, or any official LovePatrina! rights holders.

## 🌸 About the Project

*Police X Heroine Lovepatrina! Love na Rhythm de Taiho Shimasu!* is a Nintendo Switch game based on the *Police X Heroine Lovepatrina!* anime series.

This project provides an English localization of selected text and graphical assets while aiming to preserve the game's original visual identity.

## ✨ Features

- English translations of selected character descriptions and dialogue.
- English text integrated into graphical assets.
- Original character names and Lovepatrina terminology preserved where possible.
- Text formatting adapted to the Nintendo Switch interface.
- Original colors and UI style preserved wherever possible.

## 🎮 Installation

You will need:

- A legally obtained copy of *Police X Heroine Lovepatrina! Love na Rhythm de Taiho Shimasu!*.
- A compatible Nintendo Switch modding environment or emulator with game mod support.
- A backup of your original game files.

### Installation Steps

1. Download the latest patch from the [Releases](../../releases) section.
2. Extract the archive.
3. Follow the folder structure provided with the release.
4. Place the replacement files in the 0100E55012BE8000 directory.
5. Enable the mod and launch the game.

**Important:** The exact installation path depends on your environment. Consult any installation instructions included in the release and back up original game data before making changes.

## 🐛 Bug Reports

If you encounter an issue, please open a GitHub issue and include:

- The affected screen or character.

Reports of clipped text, untranslated Japanese content, and incorrect character names are especially helpful.
